# Imperial Fit

**Imperial Fit** is an all-in-one fitness platform designed to help users achieve their fitness goals with personalized workout plans, progress tracking, and a seamless e-commerce experience for purchasing gym gear. Whether you're a fitness enthusiast, bodybuilder, or someone starting their fitness journey, **Imperial Fit** offers tools and resources to support your goals. This platform features a personalized workout section, progress tracking, community engagement, and an integrated gym product store for all your fitness needs.

---

## 🚀 Features

- **Personalized Workout Plans**: Tailored workout programs based on your fitness level, goals, and preferences.
- **Progress Tracking**: Track and visualize your progress over time with intuitive charts and data analytics.
- **E-Commerce Store**: Browse and purchase fitness accessories, apparel, supplements, and more from the integrated online shop.
- **Fitness Community**: Engage with other users through forums and challenges to stay motivated and share progress.
- **Responsive Design**: Fully optimized for both desktop and mobile devices to offer a seamless experience across all platforms.
- **Secure Authentication**: Users can register, log in, and securely manage their data with JWT (JSON Web Tokens).
- **Interactive UI**: A clean, user-friendly interface powered by React and TailwindCSS.

---

## 🎯 Project Goal

The goal of **Imperial Fit** is to create a comprehensive fitness platform that seamlessly blends workout tracking with an e-commerce experience. It allows users to create workout plans, track their fitness journey, purchase essential fitness gear, and interact with a vibrant community of like-minded fitness enthusiasts. **Imperial Fit** is designed to empower users with tools to help them reach their fitness goals and maintain a healthy lifestyle.

## 🛠️ Technologies Used

### Frontend

- **React** – A powerful JavaScript library for building user interfaces, enabling dynamic and responsive components.
- **React Router** – For seamless navigation between different views and pages.
- **TailwindCSS** – A utility-first CSS framework for creating custom designs without writing CSS from scratch.
- **Axios** – For making HTTP requests to interact with the backend API.

### Backend

- **Node.js** – A JavaScript runtime built on Chrome's V8 engine, used for building scalable server-side applications.
- **Express.js** – A fast, unopinionated, minimalist web framework for Node.js, used for creating APIs and handling HTTP requests.
- **MongoDB** – A NoSQL database to store user data, workout plans, progress, and products in a flexible and scalable format.
- **JWT (JSON Web Tokens)** – Used for secure user authentication and session management.

### Payment Integration (Coming Soon)

- **Stripe** – For integrating secure payments to facilitate transactions for gym products and services.
